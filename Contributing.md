# Contributing

## Feedback and suggestions

The best place for feedback and suggestions is [in
discussions](https://github.com/davep/bagofstuff/discussions). Note,
however, that given the nature of this library, I'm very unlikely to
implement something that I don't have a direct need for.

## Bugs

Please report any bugs [as an
issue](https://github.com/davep/bagofstuff/issues). When doing so, please
provide as much detail as possible, include things like library version,
operating system, some details of the environment, etc.

## Pull requests

Other than for trivial fixes or agreed improvements to existing code, I'm
not accepting PRs. As is mentioned in the README and elsewhere: this is a
library that supports my personal projects.
